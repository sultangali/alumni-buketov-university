# Нижняя панель kiosk V3

## Подтверждённые дефекты и исправления

До: поиск имел отдельную строку для иконки, кнопки в узком preview переполняли строку (заявка обрезалась), фиксированные отступы390/410px не соответствовали реальной высоте клавиатуры и она перекрывала navbar.

После: компактная панель65px (без дополнительного системного safe-area), кнопки48px, SVG18px, подписи13px. Было около88px в portrait и112px в узком профиле. Все4 места стабильны: Назад, Главная, Поиск, Заявка; Назад на главной disabled. Active state относится к текущему действию, а не всегда к Главной. На390px подписи располагаются под иконками и остаются в тех же48px.

Клавиатура теперь участвует в flex layout, без absolute overlay и фиксированного резервирования390/410px. Контент прокручивается отдельно, footer остаётся над реальной клавиатурой любой раскладки; safe-area учитывается у нижнего элемента. Кнопки клавиатуры получили корректный min-width/padding для узкой ширины. Назад из поиска возвращает к исходному экрану, Home закрывает поиск/клавиатуру.

## Карта проверки

На1080×1920 и640×900: главная, факультеты, все15 страниц факультетов, все15 списков выпускников, категории teachers/laureates/veterans, все22 профиля из текущего API, QR-заявка, форма заявки, поиск с RU/KZ/EN-клавиатурой, Access и guards закрытых маршрутов.

С mock admin-сессией: admin, mod, review заявки; все3 вкладки администратора и все4 вкладки модератора на двух размерах (14 состояний). Данные/аккаунты не создавались.

Слайдшоу/заставка и PIN — модальные поверхности, намеренно закрывающие основной экран: выход касанием/кнопкой закрытия возвращает доступную navbar. Проверено закрытие. Дополнительно390px: кнопки помещаются, Назад из поиска сохраняет исходный профиль, Home отключает Назад.

Проверки измеряют4 видимые кнопки, высоту>=48px, отсутствие внутренней обрезки и перекрытий контентом/клавиатурой. Web navbar и отступ52px у select проверены на640/1080, вне kiosk отсутствует его footer. Build V3 и git diff --check прошли. Отдельно выполнен реальный idle60s сценарий; результат в route-checks.json.

Первый Chromium падал при длинной серии перезагрузок. Полный обход повторён в Chromium Headless Shell с отдельной страницей на маршрут; не использовал пользовательскую preview-вкладку. Физический Android не проверен.
