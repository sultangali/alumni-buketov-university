# V3 — поиск по факультету и карточки факультетов

На главной рядом с именем постоянно виден select «Факультет / Все факультеты», включая узкий kiosk preview. Общий FacultyFilter также подключён в отдельном поиске киоска. Выбор факультета работает без имени; имя/должность/специальность и факультет объединяются. Все15 факультетов сортируются по локализованному названию одинаково. Доступны сброс условий и возврат к исходной главной. Фокус select закрывает экранную клавиатуру; Home сбрасывает локальные условия, в том числе при повторном нажатии на главной.

Карточки факультетов сохранили аббревиатуры без новых тематических иконок. Добавлены мягкая глубина, белая область аббревиатуры и спокойная стрелка перехода. Одинаковый стиль всех15 карточек, реальные counts сохранены.

Проверки: build успешен; frontend12/12 (11 вложенных+родительский), включая пересечение имени/KZ/факультета и сброс. Браузер520kiosk/1080portrait/390mobile/1440desktop:16 option (все+15), выбор факультета, совмещённый поиск, Reset/Home, переходы карточек, отсутствие обрезки и ошибок JS. Результаты checks.json; снимки narrow-search.png, faculty-cards-closeup.png и остальные layouts в этой папке.
