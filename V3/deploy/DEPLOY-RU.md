# V3 — пакет для локального веб-сервера

Сборка для показа, 9 сентября 2026. Содержит все пять анимаций и утверждённый фон киоска.

## Размещение рядом с V1/V2

1. Распакуйте архив в отдельную папку. Внутри `V3/app/dist` — готовая статика; `V3/app/src` — исходники.
2. Скопируйте папку V3 на сервер в `/srv/alumni/V3`. Старые V1/V2 не заменяйте.
3. Используйте существующий Express API на `127.0.0.1:4000` с существующей базой MongoDB и папкой загрузок. Новый backend и seed для V3 не нужны.
4. Добавьте отдельный Nginx server block из `nginx-v3.conf.example`. Он использует порт 8083 и root `/srv/alumni/V3/app/dist`. При другом пути измените root.
5. Проверьте `sudo nginx -t`, затем выполните `sudo systemctl reload nginx`.
6. Откройте `http://IP-СЕРВЕРА:8083/?preview=browser&page=home`. Киоск: `http://IP-СЕРВЕРА:8083/?preview=kiosk&page=home`.

Статику можно загрузить без Node.js на сервере. API должен быть запущен отдельно: если он остановлен, загрузка профилей завершится ошибкой. Перенос на новый сервер требует существующей базы и media — они не входят в архив. Не запускайте seed вместо переноса данных.

## Завтрашний показ

Слайд-шоу открывается кнопкой в верхней панели киоска. Карточки меняются каждые 6 секунд. Для скрытого меню удерживайте полоску прогресса примерно 1,5 секунды. Доступны Карусель, Стопка, Переворот, Веер, Перекладка. Выбор запоминается в этом браузере. Нажатие на карточку закрывает слайд-шоу.

Готовый dist собран с `VITE_PRESENTATION_MODE=true`, чтобы скрытый переключатель был доступен на сервере. После показа пересоберите без этого флага, чтобы убрать выбор эффектов. Анимации сохранятся в исходниках.

Необязательный демонстрационный альбом Айданы: добавьте `&demoMedia=1` к адресу её профиля. Стоковые фотографии в этом примере требуют интернета; они не являются личными материалами Айданы. Обычный интерфейс, логотипы и шрифты работают без внешних CDN. Демоальбом не меняет базу.

## Повторная сборка

В папке V3/app:

```sh
npm ci
VITE_PRESENTATION_MODE=true npm run build
```

Обычная сборка без демонстрационного меню:

```sh
npm run build
```

Размещайте V3 на отдельном порту или hostname, не в подпапке `/v3`: маршруты, assets, API и media используют корневые пути.

## Проверка после загрузки

- `/api/health` возвращает успешный ответ.
- Главная показывает факультеты и профили.
- Прямое открытие профиля и обновление страницы работают.
- На киоске открывается слайд-шоу; стрелки и скрытое меню реагируют.

Локальная сборка и браузерные проверки выполнены. Реальный Nginx сервера и физический киоск требуют проверки после установки.
